Keyboard Shortcuts

Shortcut Keys Used in the Lighthouse V7 Application

  • ALT + Q - QUICK SEARCH
  • ALT + L - LOGOUT
  • ALT + R - REFRESH OBJECT
  • F2 - DEVELOPER MODE
  • F9 - Open LOV

Shortcut Keys Used in the Lighthouse ERP

  • ESC - Escape / Close the LOV
  • ALT + Right Arrow - Next Record
  • ALT + Left Arrow - Previous Record
  • ALT + A - Approve
  • ALT + B - Back / Exit
  • ALT + C - Cancel
  • ALT + L - Logout
  • ALT + N - Create New
  • ALT + P - Print
  • ALT + Q - Quick Search
  • ALT + R - Object Refresh
  • ALT + S - Save
  • ALT + U - Un-Approve
  • ALT + V - View
  • ALT + X - Delete
  • ALT + F1 - Help
  • CTRL + A - Attach Document
